3.3 Inter-Agent Communication: QKD-Secured Message Bus
[!NOTE]Â Why QKD for Agent Communication?Â Traditional multi-agent systems use TLS or mTLS for inter-agent communication. In a Zero Trust SOC, if any agent is compromised (e.g., via prompt injection), the attacker gains access to the entire message bus. QKD provides:
Information-theoretic security â€” no computational assumption can be broken
Eavesdropping detection â€” any interception disturbs quantum states (QBER monitoring)
Forward secrecy â€” compromised keys reveal nothing about past/future communication
Agent authentication â€” quantum identity verification prevents agent impersonation
